# Sobre el simulador
Para el proyecto necesitamos un entorno donde utilizar nuestros controles de Arduino si desea mas info ver [ descripción del proyecto ]( ../README.md ). <br>
Esta parte del proyecto es un simulador/videojuego de conducción creado con html, css, three.js, diseños hechos en blender, OpenGL (en la web) 
> nota: (si añado otra libreria/tecnología/lo que sea más adelante lo pondre aquí)
El simulador/juego no va a ser tan amplio, la idea principal es un simulador de conducción donde podamos simular (valga la redundancia) varios veiculos siendo estos: distintos tipos de carros: particular, (trasmilenio implementación mas adelante) y motos(: bajo, mediano y alto cilindraje caracteristicas que implementare mas afondo del proyecto / si hay tiempo 😁)

## Objetivos

Crear un simulador web donde se puedan implementar los controles creados con HTML, CSS, JS, THREE.JS, OpenGL y diseños hechos en blender
