# Sobre el simulador
Para el proyecto necesitamos un entorno donde utilizar nuestros controles de Arduino si desea mas info ver [ descripción del proyecto ]( ../README.md ). <br>
Esta parte del proyecto es un simulador/videojuego de conducción creado con html, css, three.js, diseños hechos en blender, OpenGL (en la web) 
> nota: (si añado otra libreria/tecnología/lo que sea más adelante lo pondre aquí)
El simulador/juego no va a ser tan amplio, la idea principal es un simulador de conducción donde podamos simular (valga la redundancia) varios veiculos siendo estos: distintos tipos de carros: particular, (trasmilenio implementación mas adelante) y motos(: bajo, mediano y alto cilindraje caracteristicas que implementare mas afondo del proyecto / si hay tiempo 😁)

# Proyecto de Embebidos (proyecto_embebidos)
Este es un proyecto de tercer semestre para la asignatura de embebidos el cual tiene como propósito desarrollar las habílidades de los ingenieros en la resolución de problemas basados en los [sistemas embebidos](https://reboundeu.com/es/insights/blog/embedded-systems-explained-15/#:~:text=%C2%BFQu%C3%A9%20es%20un%20sistema%20embebido,un%20dispositivo%20multifunci%C3%B3n%20m%C3%A1s%20grande.) utilizando ["Arduino"](https://www.xataka.com/basics/que-arduino-como-funciona-que-puedes-hacer-uno): 
>"Arduino es una plataforma de creación de electrónica de código abierto, la cual está basada en hardware y software libre, flexible y fácil de utilizar para los creadores y desarrolladores. Esta plataforma permite crear diferentes tipos de microordenadores de una sola placa a los que la comunidad de creadores puede darles diferentes tipos de uso" 

![Arduino](https://cdn.pixabay.com/photo/2017/03/23/12/32/arduino-2168193_1280.png)

## ¿Qué pide la materia?
Un proyecto complejo, universitario hecho con arduino u otra placa de desarrollo el cual sea un sistema embebido y funcione correctamente según lo planeado.
## Objetivos del proyecto
### Objetivo Especifico:
Crear un videojuego (en la web) de conducción que se pueda controlar con unos controles físicos externos conectados al computador mediante una conección usb controlados con una placa de desarrollo arduino:
1. Volante.
2. Pedales: Acelerar, embrague y frenar.
3. Caja de cambios 5 cambios y reversa.
